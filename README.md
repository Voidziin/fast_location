# FastLocation

Aplicativo Flutter para consultar endereços pelo ViaCEP e localizar os resultados em aplicativos de mapas.

## Funcionalidades

- Consulta de endereço por CEP.
- Consulta de CEP por UF, cidade e rua ou trecho.
- Armazenamento local do histórico e do último endereço consultado.
- Interface reativa com MobX.
- Histórico de consultas.
- Traçar rota para o último endereço consultado.

## Executar

```bash
flutter pub get
flutter run
```

O projeto foi configurado para Android e iOS.
